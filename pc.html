東京徳純院 業務管理システム ― Mac（パソコン）の設定

このページでは、Macで次の2つの設定をします。どちらも1回やれば終わりです（全部で5分ほど）。

  • ① Macの電源を入れたら、業務管理システムが自動で開くようにする
  • ② 閉じてしまった時のために、画面にアイコンを置く（ダブルクリックで開く）

このページは、設定するMacで開いてください。分からない時は、無理に進めずに管理者に声をかけてください。

この説明に出てくる言葉

command キーキーボードの一番下の段、スペースキーのすぐ左右にある ⌘ command と書かれたキー
return キーキーボードの右側にある大きなキー return（「決定」のキー）
英数 キースペースキーの左にある 英数。押すと、英字（アルファベット）が打てるようになります
デスクトップMacの画面の背景の部分（窓が何も開いていない所）
Finder（ファインダー）画面の一番下に並ぶアイコン（Dock）の左はしにある、青と白の顔のマーク。ファイルを探す時に使います
ドラッグマウス（またはトラックパッド）のボタンを押したまま動かし、目的の所で離すこと

① Macの電源を入れたら、自動で開くようにする

「ターミナル」という、文字で命令を打つアプリに、下の文を貼り付けます。むずかしいことはしません。コピーして、貼り付けて、return を押すだけです。

  1. 下の「コピーする」ボタンを押す curl -fsSL https://fukuokatokujunin.github.io/tokyo-gyomu/pc/mac-autostart.sh | bash ボタンの文字が「コピーしました ✓」に変わる（画面には何も出ませんが、これで覚えています）
  2. キーボードの ⌘ command を押したまま、スペース を押す
    🔍Spotlight検索
    画面のまん中に、細長い検索の窓が出る
  3. 英数 キーを押してから、terminal と打つ
    🔍terminalターミナル

    ひらがなのまま「たーみなる」と打つと、うまく開かないことがあります。必ず英字で。

  4. return キーを押す
    ターミナル
    Last login: …
    ~ % _
    上の図のような、文字だけの窓（ターミナル）が開く
    画面の一番下の Finder（青と白の顔のマーク）を押す → 窓の左の「アプリケーション」→「ユーティリティ」フォルダをダブルクリック →「ターミナル」をダブルクリック。
  5. ターミナルの窓の中を1回クリックしてから、⌘ command を押したまま V を押す

    これで、手順1でコピーした文が貼り付けられます。

    ターミナル
    ~ % curl -fsSL https://fukuokatokujunin.github.io/tokyo-gyomu/pc/mac-autostart.sh | bash
    「curl -fsSL https://…」で始まる長い文が出る
  6. return キーを押す

    「“ターミナル”が“System Events”を制御しようとしています」という確認が出たら「OK」（または「許可」）を押します。

    ターミナル
    ✅ 設定しました。いまブラウザで東京の業務管理システムが開けば成功です（次回からMacの起動時に開きます）。
    「✅ 設定しました」と出て、ブラウザ（Chrome や Safari）で業務管理システムが開く
  7. ターミナルを閉じる

    ターミナルの窓の左上の赤い丸を押して閉じます。これで①は終わりです。次からは、Macの電源を入れるたびに業務管理システムが開きます。

    「✅ 設定しました」が出ない、赤い字（英語）が出た時は、その画面のまま管理者に見せてください。

② 画面（デスクトップ）にアイコンを置く

業務管理システムを閉じてしまった時に、ダブルクリックするだけで開けるアイコンを作ります（アプリと同じロゴの絵です）。

ZIP東京業務管理システム.zip

東京業務管理システム
➜
デスクトップへ
  1. 下の「アイコンをダウンロード」ボタンを押す アイコンをダウンロード

    「ダウンロードを許可しますか？」などと聞かれたら「許可」（または「保存」）を押します。

    Macの「ダウンロード」フォルダに「東京業務管理システム.zip」が入る
  2. 「ダウンロード」フォルダを開く

    画面の一番下の Finder（青と白の顔のマーク）を押し、出てきた窓の左側の「ダウンロード」を押します。

    よく使う項目

    すぐ横に、ロゴの絵の「東京業務管理システム」ができる
  4. ロゴの絵の「東京業務管理システム」を、デスクトップへドラッグ

    アイコンの上でマウスのボタンを押したまま、画面の背景（窓のない所）まで動かして離します。窓が画面いっぱいで背景が見えない時は、窓を少し動かしてから行います。

    画面の背景にロゴのアイコンが置かれる。ダブルクリックすると業務管理システムが開く

お好みで：アイコンを画面の一番下（Dock）のゴミ箱の左側へドラッグすると、1回押すだけで開けるようになります。
